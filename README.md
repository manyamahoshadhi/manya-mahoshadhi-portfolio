# Manya — Software Engineer Portfolio

Premium personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, and React Icons.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Customize Content

Edit `src/data/portfolio.js` to update:

- Personal info, social links, resume URL
- About, skills, projects, experience, education, certifications

Replace `public/resume.pdf.txt` with your real `resume.pdf` and set `resumeUrl: '/resume.pdf'` in the data file.

Replace the avatar initial in the Hero with your photo when ready.

## Stack

- React 19 + Vite
- Tailwind CSS 3
- Framer Motion
- React Icons
